How it knows where to paste

There is no per‑app integration. You click into the target field on your Mac first (a chat box, an email, a doc), then dictate. The server puts the text on the clipboard and presses ⌘V, so it lands exactly where your cursor is — in any app.

Away from home? Same bridge over Tailscale

Install Tailscale on the Mac and the phone. The Mac gets a stable tailnet address (e.g. 100.x.y.z or a name like mac‑studio) — put that in the app's host field instead of the LAN IP. The WireGuard tunnel is encrypted end‑to‑end, so plain HTTP inside it is fine and you need no certificates. Start the server with --token (or WHISPERFLOW_TOKEN) and paste the same value into the app's Token field so every request must carry it. Leave Tailscale Funnel off — that would publish the port to the open internet.
